# Lab 28 — Mobile and Endpoint Hardening Baseline — Instructions

## How to run this lab

1. Open the free Killercoda Ubuntu Playground: https://killercoda.com/playgrounds/scenario/ubuntu
2. Work through **README.md** step by step, running each command block in the playground shell.
3. Or run every command block in order with the helper script (review it first):

   ```bash
   sudo bash scripts/run.sh
   ```

4. Tick every item in **checklist.md** before moving on.

## Steps in this lab

1. Install the tools
2. Establish the baseline and the Wi-Fi profile
3. Deploy the passcode policy
4. Enforce screen lock and idle timeout
5. Require encryption for the secure folder
6. Enforce the app deny-list and block sideloading
7. Disable unneeded radios and services, and detect root-level tampering
8. Verify compliance with a check script

> Reset the playground between labs that change firewall, PAM, routing or disk state.
