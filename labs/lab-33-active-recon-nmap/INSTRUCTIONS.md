# Lab 33 — Active Reconnaissance with Nmap — Instructions

## How to run this lab

1. Open the free Killercoda Ubuntu Playground: https://killercoda.com/playgrounds/scenario/ubuntu
2. Work through **README.md** step by step, running each command block in the playground shell.
3. Or run the whole lab non-interactively with the helper script:

   ```bash
   sudo bash scripts/run.sh
   ```

4. Confirm every item in **checklist.md** is ticked before moving on.

## Steps in this lab

- Step 1 — Install
- Step 2 — Host discovery (no port scan yet)
- Step 3 — TCP SYN scan (the default)
- Step 4 — Service / version detection
- Step 5 — OS fingerprint
- Step 6 — NSE (Nmap Scripting Engine)
- Step 7 — Vulnerability scripts
- Step 8 — Timing & stealth (`-T0` … `-T5`)
- Step 9 — Save in three formats for reporting
- Step 10 — Rules of engagement reminder

> Reset the playground between labs that change firewall, PAM, routing or disk state.
