# Lab 04 — Change Management with Version-Controlled Configuration — Instructions

## How to run this lab

1. Open the free Killercoda Ubuntu Playground: https://killercoda.com/playgrounds/scenario/ubuntu
2. Work through **README.md** step by step, running each command block in the playground shell.
3. Or run every command block in order with the helper script (review it first):

   ```bash
   sudo bash scripts/run.sh
   ```

4. Tick every item in **checklist.md** before moving on.

## Steps in this lab

1. Install the tools
2. Put /etc under version control and record the baseline
3. Raise the change request
4. Run the impact analysis
5. Stage and test the change
6. Approve and implement in the maintenance window
7. Commit the change and update the documentation
8. Detect an unauthorised change and execute the backout plan

> Reset the playground between labs that change firewall, PAM, routing or disk state.
