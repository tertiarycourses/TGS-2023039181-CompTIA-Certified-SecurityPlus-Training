# Lab 02 — CIA Triad and AAA on Linux — Instructions

## How to run this lab

1. Open the free Killercoda Ubuntu Playground: https://killercoda.com/playgrounds/scenario/ubuntu
2. Work through **README.md** step by step, running each command block in the playground shell.
3. Or run every command block in order with the helper script (review it first):

   ```bash
   sudo bash scripts/run.sh
   ```

4. Tick every item in **checklist.md** before moving on.

## Steps in this lab

1. Install the tools and create the lab users
2. Confidentiality: restrict a file to its owner
3. Integrity: baseline a hash and detect tampering
4. Availability: make a service self-heal
5. Authentication of people: verify a password hash
6. Authentication of systems: log in with an SSH key
7. Authorization: grant one least-privilege sudo command
8. Accounting: trace who did what in the logs

> Reset the playground between labs that change firewall, PAM, routing or disk state.
