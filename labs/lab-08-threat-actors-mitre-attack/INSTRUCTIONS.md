# Lab 08 — Threat Actors & the MITRE ATT&CK Framework — Instructions

## How to run this lab

1. Open the free Killercoda Ubuntu Playground: https://killercoda.com/playgrounds/scenario/ubuntu
2. Work through **README.md** step by step, running each command block in the playground shell.
3. Or run every command block in order with the helper script (review it first):

   ```bash
   sudo bash scripts/run.sh
   ```

4. Tick every item in **checklist.md** before moving on.

## Steps in this lab

1. Install the tools
2. Download the ATT&CK Enterprise dataset
3. Confirm the dataset loaded
4. List the intrusion sets (threat groups)
5. Profile one group's aliases and description
6. Extract the techniques attributed to the group
7. Classify the actor type and motivation
8. Record the profile as a threat note

> Reset the playground between labs that change firewall, PAM, routing or disk state.
