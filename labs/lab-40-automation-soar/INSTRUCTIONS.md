# Lab 40 — Automation and Orchestration with a Mini-SOAR Playbook — Instructions

## How to run this lab

1. Open the free Killercoda Ubuntu Playground: https://killercoda.com/playgrounds/scenario/ubuntu
2. Work through **README.md** step by step, running each command block in the playground shell.
3. Or run every command block in order with the helper script (review it first):

   ```bash
   sudo bash scripts/run.sh
   ```

4. Tick every item in **checklist.md** before moving on.

## Steps in this lab

1. Install the tools
2. Automate user provisioning from an HR feed
3. Start a mock ticketing and paging API
4. Write the playbook with guard rails
5. Test the playbook the CI way before it touches production
6. Run the playbook as a service
7. Trigger an incident and watch the automated response
8. Roll back: re-enable access after review

> Reset the playground between labs that change firewall, PAM, routing or disk state.
